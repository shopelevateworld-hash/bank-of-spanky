# BANK OF SPANKY

Luxury black-and-gold editorial landing page for BANK OF SPANKY.

## Run locally

Open index.html in a browser. No build step or framework is required.

## Deploy

Static site. Enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).

## Brand note

BANK OF SPANKY is presented as a fictional digital-culture and entertainment institution, not a real bank or financial service.
